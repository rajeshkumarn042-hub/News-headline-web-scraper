 NEWS HEADLINE WEB SCRAPER:

PROJECT OVERVIEW:

This project is a simple web scraper developed using Python. It collects the latest news headlines from the BBC News website and stores them in a text file for easy access and analysis.

 OBJECTIVE:

The main objective of this project is to automate the process of extracting news headlines from a public website using web scraping techniques.

 TECHNOLOGIES USED:

- Python
- Requests Library
- BeautifulSoup (bs4)

 FEATURES:

- Connects to the BBC News website
- Fetches webpage content using HTTP requests
- Extracts news headlines from HTML tags
- Displays headlines in the terminal
- Saves headlines to a text file automatically



HOW TO WORK:

1. Sends a request to the BBC News website.
2. Downloads the webpage content.
3. Parses the HTML using BeautifulSoup.
4. Extracts headline text from `<h2>` tags.
5. Saves the headlines into `headlines.txt`.

 SAMPLE OUTPUT:

 LEARNING OUTCOMES:

- Understanding web scraping concepts
- Working with Python libraries
- Extracting and processing HTML data
- Saving scraped data into files
